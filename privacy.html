Léa Studio — Privacy Policy

Last updated: October 12, 2026

1. Introduction

Léa Studio is an independent AI-assisted creative project focused on planning, preparing, and reviewing digital photo and video content.

2. Current Website

This informational website does not currently require visitors to create accounts or provide personal information.

3. Website Hosting

This website is hosted through GitHub Pages. GitHub may process technical information, such as IP addresses and browser information, according to its own privacy policies.

4. TikTok Integration

Léa Studio is developing optional integrations with TikTok. TikTok account connections and content-related features are not currently publicly available.

Before activating any TikTok integration, this policy will be updated to explain the specific account information, permissions, purposes, storage practices, and retention periods involved.

5. Artificial Intelligence

Léa Studio explores AI-assisted workflows for planning visual content, organizing creative projects, and reviewing photos and videos.

Information about any future AI services that process personal information will be provided before those services become available.

6. Data Sharing

The current informational website does not provide a feature for visitors to upload personal content to Léa Studio. Third-party hosting services may process technical information required to operate the website.

7. Data Security

Léa Studio aims to apply appropriate security safeguards to any future features that process personal information.

8. Your Privacy Rights

Where applicable, individuals may have rights to request access to, correction of, or deletion of their personal information. Privacy requests will be handled in accordance with applicable laws.

9. Changes to This Policy

This privacy policy may be updated as the project evolves. The latest version will be published on this page.

10. Contact

For information about the project, visit the Léa Studio GitHub repository.

Please do not post sensitive personal information in public GitHub discussions.
